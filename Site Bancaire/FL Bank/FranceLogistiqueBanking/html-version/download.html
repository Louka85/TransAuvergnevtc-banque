📥 Comment Installer l'Application

  1. Sur Mobile (Android/iOS) :
    • Ouvrir le lien ci-dessus dans votre navigateur
    • Menu (3 points) → "Ajouter à l'écran d'accueil"
    • L'app apparaîtra sur votre écran d'accueil
  2. Sur PC (Windows/Mac) :
    • Ouvrir le lien dans Chrome ou Edge
    • Cliquer sur l'icône d'installation dans la barre d'adresse
    • L'app s'ouvrira dans une fenêtre dédiée
